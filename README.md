# PLAYEROK PROFIT AI MAX — бесплатный Telegram-менеджер цифровых товаров

Полноценная расширенная основа для управления магазином цифровых товаров через Telegram.
Без платных AI API, платных прокси и обязательных подписок.

## Ключевой принцип
Бот автоматизирует подготовку, учёт, расчёты, напоминания и шаблоны общения. Любое действие, которое может потратить деньги или изменить магазин на площадке, требует отдельного подтверждения владельца.

**Важное ограничение:** в комплекте нет подтверждённого официального API Playerok. Поэтому бот не притворяется, что умеет читать заказы/публиковать товары/отправлять сообщения на Playerok напрямую. Он ведёт локальную очередь, готовит материалы и фиксирует решения. Для реального обмена с площадкой позже нужен документированный разрешённый API/интеграция. Не вставляйте в проект cookies, пароли, коды 2FA и не используйте обход CAPTCHA/антибота.

## Возможности
- Telegram-панель администратора с проверкой `ADMIN_ID`.
- Каталог товаров: название, категория, цена, описание, себестоимость, остаток.
- Загрузка фотографий к товару из Telegram.
- Генерация простой карточки/обложки из загруженного фото или без фото средствами Pillow (без AI и внешних сервисов).
- Черновики объявлений и очередь подтверждения публикации.
- Закупочные возможности: расчёт ожидаемой прибыли, ROI, резерва комиссии; подтверждение/отклонение каждой сделки.
- Учёт заказов и статусов: новый → оплачен → выдан → завершён/проблема.
- Шаблоны сообщений покупателю: приветствие, уточнение, инструкция выдачи, завершение, решение проблемы.
- Подготовка персонального сообщения по заказу; копирование/отправка вручную. Автоматическая отправка на Playerok не заявляется без API.
- Склад, выручка, себестоимость, оценка прибыли.
- Импорт CSV с рыночными ценами.
- Журнал действий и SQLite.
- Экспорт отчёта CSV.
- Все ключевые действия доступны командами; краткая справка в `/help`.

## Установка
Нужен Python 3.11+.

1. Распакуйте ZIP на хостинге с постоянным диском.
2. Создайте Telegram-бота через `@BotFather`.
3. Скопируйте `.env.example` в `.env`.
4. Заполните `TELEGRAM_BOT_TOKEN` и `ADMIN_ID`.
5. В терминале из папки проекта:
   ```bash
   python -m venv .venv
   # Linux:
   source .venv/bin/activate
   # Windows:
   .venv\Scripts\activate
   pip install -r requirements.txt
   python main.py
   ```
6. В панели хостинга задайте команду запуска `python main.py`. Включите постоянное хранение папок `data/` и `media/`.

## Первые команды
- `/start` — старт и краткое меню
- `/help` — полный список команд
- `/addproduct` — добавить товар, затем можно прислать фото
- `/products` — каталог
- `/photo ID` — заменить/добавить фото товару
- `/makecard ID` — создать рекламную карточку из фото/шаблона
- `/draft ID` — создать черновик объявления по товару
- `/drafts` — очередь черновиков
- `/adddeal` — добавить закупочную возможность
- `/deals` — закупки и решения
- `/addorder` — добавить заказ вручную
- `/orders` — список заказов
- `/order ID` — карточка заказа
- `/paid ID` — отметить заказ оплаченным
- `/setdelivery ID` — сохранить текст/инструкцию выдачи для заказа\n- `/deliver ID` — подготовить сообщение покупателю о выдаче
- `/done ID` — отметить заказ завершённым
- `/templates` — показать шаблоны сообщений
- `/report` — сводка
- `/export` — выгрузить отчёт CSV
- `/importcsv` — импорт рыночной CSV-выгрузки
- `/market` — анализ импортированных цен
- `/cancel` — отменить текущий ввод

## Фото
Есть два варианта:
1. При добавлении товара или через `/photo ID` отправьте фотографию в чат. Бот сохранит её в `media/`.
2. `/makecard ID` создаст карточку: если у товара есть фото — использует его; иначе сделает графическую обложку с названием и ценой.

Карточка — это визуальный макет для объявления, а не доказательство свойств товара. Не добавляйте чужие логотипы, чужие скриншоты, персональные данные, фальшивые чеки или изображения, вводящие покупателя в заблуждение. Для цифрового товара лучше загружать собственный скриншот/иллюстрацию, не содержащую секретов и данных аккаунта.

## Сообщения покупателю
После регистрации заказа используйте `/deliver ID`. Сначала можно сохранить индивидуальную инструкцию через `/setdelivery ID`. Бот подставит название товара, номер заказа и подготовит текст выдачи. Шаблон можно редактировать в `templates.py`.
Если выдача требует секретного кода/ключа, отправляйте его только через разрешённый и безопасный канал площадки. Не храните пароли, 2FA-коды или данные чужих аккаунтов в SQLite. По умолчанию бот не отправляет сообщение на Playerok: он формирует текст для копирования. Отправка через площадку возможна только после подключения документированного API.

## Формат CSV для рынка
Обязательные заголовки: `title,price,category`; дополнительные: `url,source,notes`.
Пример в `examples/market_sample.csv`.

## Финансовая логика
Оценка чистой прибыли = цена продажи − себестоимость − резерв комиссии/расходов.
ROI = чистая прибыль / себестоимость × 100%.
Это прогноз, а не гарантия. Проверяйте ограничения площадки, права на товар, регион, срок действия и реальную ликвидность.

## Хостинг и безопасность
- На бесплатном хостинге процесс может засыпать. Нужен тариф/платформа, где разрешён постоянно работающий бот.
- SQLite и фото хранятся на диске хостинга. Если файловая система эфемерная, подключите persistent volume или регулярно делайте бэкап.
- Не публикуйте `.env`.
- Не отправляйте боту пароли, cookies, коды 2FA, seed-фразы и платёжные данные.
- Бот предназначен для одного владельца. Для нескольких сотрудников сначала добавьте отдельную систему ролей.
