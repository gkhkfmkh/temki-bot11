# Playerok Manager PRO — без ИИ

Telegram-панель для подготовки карточек товаров, хранения черновиков, шаблонов ответов и локальной статистики. ИИ, OpenAI, Gemini и любые AI API не используются.

## Что умеет
- Пошагово создать карточку: игра, категория, название, цена, факты и до 10 фото.
- Сохранить карточки в SQLite и посмотреть их список.
- Показать карточку и подготовить текст для ручной публикации на Playerok.
- Удалить локальный черновик (это не удаляет объявление на Playerok).
- Создавать шаблоны ответов по ключевым словам и проверять, какой подходит к сообщению.
- Смотреть локальную статистику, искать карточки по названию/игре/описанию.
- Делать резервную копию базы.

## Важные ограничения Playerok
Бот не подключается к аккаунту Playerok и не читает личные сообщения, заказы или реальные продажи. Новые объявления создаются вручную на сайте. Бот не автоматизирует создание или удаление объявлений и не просит пароль, cookies, токены сессии или коды подтверждения. Раздел перевыставления — информационная памятка о штатной настройке площадки, а не автоматическое управление аккаунтом.

## Установка на Windows
1. Установи Python 3.11 или 3.12.
2. Распакуй архив.
3. В PowerShell в папке проекта выполни:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

4. Скопируй `.env.example` в `.env`.
5. Укажи `BOT_TOKEN` и свой числовой `ADMIN_IDS`.
6. Запусти `python bot.py`.

## Команды
- `/start`, `/menu` — главное меню.
- `/new` — создать карточку.
- `/products` — список карточек.
- `/stats` — локальная статистика.
- `/search текст` — поиск карточек.
- `/backup` — отправить резервную копию базы.

## Переменные окружения
- `BOT_TOKEN` — токен Telegram-бота.
- `ADMIN_IDS` — Telegram ID администраторов через запятую.
- `DB_PATH` — путь к SQLite, по умолчанию `data/playerok.sqlite3`.

Не публикуй `.env` и не отправляй токен бота другим людям.
