# Playerok Manager PRO

Telegram-панель для локального управления черновиками товаров, ИИ-генерации текстов,
шаблонами ответов и локальной статистикой.

## Важные ограничения

- Создание новых объявлений выполняется вручную на Playerok: бот готовит карточку и черновик.
- Автоматическое создание/удаление товаров не реализовано.
- Модуль «Перевыставление» в этой сборке — справочный/учётный: он напоминает проверить штатную настройку Playerok «Оставить в продаже».
- Бот не подключается к личным сообщениям Playerok, не отправляет ответы на площадку и не подтверждает сделки.
- Статистика показывает данные, сохранённые в этой локальной панели, а не реальные продажи Playerok.
- Не вводи в бота пароли, cookies, токены сессии или коды подтверждения Playerok.

## Установка Windows

1. Установи Python 3.11 или 3.12 с сайта python.org. При установке отметь `Add Python to PATH`.
2. Распакуй архив в отдельную папку, например `C:\PlayerokManagerPRO`.
3. Открой PowerShell в этой папке.
4. Создай виртуальное окружение:

   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   Если PowerShell блокирует активацию, используй CMD:
   `.\.venv\Scripts\activate.bat`

5. Установи библиотеки:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

6. Скопируй `.env.example` в `.env`.
7. В `.env` укажи `BOT_TOKEN` и свой числовой `ADMIN_IDS`.
8. Для хостинга добавь `BOT_TOKEN`, `ADMIN_IDS` и `GEMINI_API_KEY` в раздел переменных окружения. Локально скопируй `.env.example` в `.env` и заполни значения. Модель задаётся через `GEMINI_MODEL`. Не отправляй API-ключ никому. Если ключа нет, сохранение черновиков работает без ИИ.
9. Запусти:

   ```powershell
   python bot.py
   ```

10. Открой Telegram-бота и отправь `/start`.

## Как узнать Telegram ID

Напиши в Telegram боту, который показывает твой числовой user ID, и перенеси только число в `ADMIN_IDS`.
Не используй username вместо ID.

## Основные функции

- Создание карточки через пошаговый диалог.
- До 10 фотографий в черновике.
- ИИ-генерация названия, описания, преимуществ, FAQ и ключевых слов.
- ИИ-редактирование карточки по запросу.
- Сохранение товаров в SQLite.
- Список, просмотр и удаление локальных черновиков.
- Шаблоны ответов по ключевым словам.
- Проверка подходящего ответа вручную.
- Переключение режима автоответчика в настройках (режим пока относится к локальному подбору, а не к отправке на Playerok).
- Локальная статистика и журнал событий.
- Резервная копия базы командой `/backup`.

## Безопасность

- Не публикуй `.env`.
- Не присылай никому `BOT_TOKEN` и `GEMINI_API_KEY`.
- Не храни в карточках пароли, чужие персональные данные или секреты.
- Всегда проверяй текст ИИ, цену, фото, категорию и условия передачи.
- Не доверяй ИИ решение о передаче товара или завершении сделки.
- Делай резервные копии папки `data` и `storage`.

## Структура

- `bot.py` — Telegram-интерфейс.
- `database.py` — SQLite.
- `ai_service.py` — генерация карточек.
- `data/` — база.
- `storage/photos/` — фотографии черновиков.
- `logs/` — журнал.
- `backups/` — резервные копии.
